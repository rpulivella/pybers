As the maintainer preparing pybers for open source I want a logo and an icon so that the project is recognizable on GitHub and wherever it is linked.

## Acceptance criteria

1. The README opens with the logo, legible in both GitHub's light and dark themes.
1. The repository's GitHub social preview shows the logo.
1. A square icon derived from the logo stays legible at 16 by 16 pixels.
1. The logo and the icon are committed as vector source beside their exported images, so either can be exported again at any size.
1. Neither uses Apple's Numbers icon, its name styling or its trade dress.

## Constraints

- Still open: the mark itself, its colors, and who designs it.
