# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Report a vulnerability privately through GitHub's private vulnerability reporting, with the **Report a vulnerability** button on the repository's [Security tab](https://github.com/rpulivella/pybers/security). A public issue, discussion or pull request is the wrong place, because it discloses the problem before a fix exists.

Include the pybers version or commit, what an attacker gains, and the steps or the `.numbers` file that reproduce it.

## What follows a report

A maintainer acknowledges the report within seven days. If it is not a vulnerability, the reply says why. Once the fix is public, the reporter is told, and the advisory credits them unless they ask otherwise.
