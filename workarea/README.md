# workarea: ephemeral scratch (git-ignored)

This folder is **not committed** (only this README is). It is the current-moment scratch
space, never synced, safe to delete wholesale.

What lives here: WIP experiments, fixture `.numbers` files pulled in for testing, design
notes, throwaway scripts, anything not ready to be a real decision yet.

The committed counterpart, the durable "brain" agents read from, is `../docs/` and
`../CLAUDE.md`. Anything worth keeping belongs there, not here.

`workarea/session-tasks.md`, when present, is the current-session task dashboard maintained by
`/ticket-startwork`, rewritten wholesale each time, never appended to, never committed.
